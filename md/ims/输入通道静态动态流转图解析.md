### 标注说明（对应你梳理的核心逻辑）：

1. **Server端三层绑定**：

    - Java层Server InputChannel的`mPtr` → 指向Native层Server InputChannel；

    - Native层Server InputChannel的`mFd` → 绑定socket的server fd；

    - 注册时通过`getFd()`取fd，创建Connection并存入`mConnectionsByFd`（fd为key）；

2. **Client端简化绑定**：

    - 仅保留「Java InputChannel→Native InputChannel→client fd」，无Connection（无需管理通道）；

3. **核心纽带**：UNIX Socket Pair的fd0/fd1是所有组件的底层关联核心。

### 流转关键节点（对应你的核心梳理）：

1. InputDispatcher 先通过「目标窗口」找到Server InputChannel → 取fd；

2. 用fd从`mConnectionsByFd`拿到Connection → 关联Native Server InputChannel；

3. 通过Native层的`mFd`（server fd）写入事件到Socket；

4. 应用进程监听client fd可读 → 逐层解析到View树；

5. 全程无Connection参与Client端流转（仅Server端管理用）。
