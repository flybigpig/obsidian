
## Linux常用命令

1. `tar -xvzf filename.tar.gz`解压tar.gz文件
    
2. `unar 你的压缩包.zip` 解决解压后乱码问题
    
3. `find -name Activity.java`寻找当前文件夹以及自文件夹的文件
    
4. `./studio.sh`进入到android/bin中 `./studio.sh` 安装或者打开androidStudio
    
5. `grep "***" ./ -rn` linux快速检索，比在as中搜索快 ，`r`表示递归搜索。即不仅搜索当前目录，还会进入所有子目录中查找指定的模式；`n`表示显示行号
    
6. `grep "str1" ./ -rn | grep  "str2"` 在查询到str1的列表中查询str2
    
7. `xdg-open .` 从终端中打开当前文件夹所在文件管理的位置
    
8. `cat` 显示文件内容`cat filename.txt`      # 在屏幕上显示文件内容`cat -n filename.txt`   # 显示内容并显示行号
    
9. `touch` 新建文件，如果文件已存在，不会修改文件内容，只会更新文件的「最后修改时间」和「最后访问时间」为当前系统时间
    
10. `netstat -an | grep server` 查看socket
    

## git命令

1. `git add .` 和`git add *`区别 git add .      # 会添加 .gitignore
    
2. `git diff` 显示未被add的修改
    
3. `git status` 显示“已暂存（待commit）” 和 “未暂存（待add）” 的文件
    
4. `git diff --name-only` 显示未被add的修改-只显示文件名
