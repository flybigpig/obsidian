## CPU如何 工作？

CPU是计算机最核心的组成部分，它负责管理所有算术、逻辑、控制和 I/O 操作。CPU 的主要组件是控制单元 (CU)、算术和逻辑单元 (ALU) 和寄存器。

![图片](https://mmbiz.qpic.cn/mmbiz_png/FWANMMXDrgIn8SxlJp4AbeiaSCNI1ib5SyNDK4vvxuKwwMVIVKltpKXPYD04sL1T2b8Vf7S7EEIySPPPibNsXtd6w/640?wx_fmt=png&from=appmsg&wxfrom=13&tp=wxpic)

CU负责协调和管理整个CPU的运行。包括获取指令、解码指令并控制其他部件的操作。

ALU 单元负责执行算术运算（如加法、减法）和逻辑运算（如与、或、非等），CU和ALU两者协同工作来执行指令并处理数据。

CPU的运行也离不开内存（Primary Storage）和外部存储（Secondary Storage）。内存提供快速的数据存取，而外部存储（如硬盘）则用于存储大规模的数据。CPU在处理过程中可能需要频繁与内存和外部存储进行数据交互。

最开始的时候，数据传输通常是由CPU来管理的。举个例子，如果需要将硬盘中的数据传输到内存，CPU必须：

1. 从硬盘读取数据。
    
2. 将数据加载到内存中。
    
3. 然后继续处理其他任务。
    

然而，CPU在处理数据传输时需要暂停当前进程任务的执行，这会对系统整体的性能产生一定的影响，特别是在需要频繁进行数据传输的应用场景中。

![图片](https://mmbiz.qpic.cn/mmbiz_png/FWANMMXDrgIn8SxlJp4AbeiaSCNI1ib5Syiaibxayx7gea8gE1X7HyxvZCrrYyFL334c0G8lTL9ibTrS5HwjgGCV4Ng/640?wx_fmt=png&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1)

因此，为了优化数据传输的效率，最大程度地减少对CPU性能的影响，DMA就诞生了。

## 什么是DMA？

DMA，即直接内存访问，它是计算机系统中用于高效地进行数据传输的一种技术和机制，解决了外围设备和内存之间数据传输效率低下的问题。

传统上，CPU需要花费大量时间和精力去处理数据的搬运工作，这使得CPU无法专心去处理更重要的计算任务。影响整个系统的性能。

而DMA允许外部设备（如硬盘控制器、网络接口卡、音频设备等）直接访问主内存，不需要 CPU 的直接干预和参与。而CPU只需要在设置好传输参数后等待DMA完成任务。这样，CPU就能腾出时间去处理其他任务，提高系统的性能和效率。

### DMAC组成

DMA的功能主要是通过一个称为 DMA控制器（DMAC）的硬件完成的，它将直接帮助内存和 外部IO 设备之间的整个数据传输过程。

下面这张图展示了 DMA控制器的内部结构以及它如何与其他系统组件进行交互，下面逐个部分介绍这个结构。

![图片](https://mmbiz.qpic.cn/mmbiz_png/FWANMMXDrgIn8SxlJp4AbeiaSCNI1ib5SyVzInJWdBibA7V0eVG2s0YL31NYdvHJXj5kUg6qbydicLITYgjcg1G2Yw/640?wx_fmt=png&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1)

- 系统地址总线（System Address Bus）：这是用来传输地址信息的总线，DMA控制器通过它来确定数据传输的源地址（外设的地址）和目标地址（内存的地址）。
    
- 系统控制总线（System Control Bus）：控制信号通过这条总线传输，例如读/写操作的控制信号（R/W）、中断信号、DMA请求、DMA确认信号等。DMA控制器通过这个总线来控制系统的操作，特别是获取总线控制权时的交互。
    
- 系统数据总线（System Data Bus）：这是用来传输实际数据的总线。DMA控制器通过数据总线与内存、外设进行数据的交换。
    
- I/O地址解码（I/O Address Decode）：这是DMA控制器的一部分，它用来解码来自外设的地址信息，确定数据应该从哪里读取或者写入。
    
- 内存地址寄存器（Memory Address Register）：它存储内存的地址信息，即数据传输的目标位置。当DMA控制器需要将数据传输到内存时，这个寄存器指定内存地址。
    
- 字节计数寄存器（Byte Count Register）：这个寄存器用来存储待传输的数据的字节数，DMA控制器根据这个寄存器来控制数据传输的长度。
    
- 设备状态和控制逻辑（Device Status and Control Logic）：它负责与外设的交互，控制外设的操作并读取外设的状态信息。通过它，DMA控制器可以得知外设的状态，决定何时开始传输。
    
- 数据缓冲区（Data Buffering）：DMA控制器内部的数据缓冲区用来暂时存储数据，在数据传输过程中起到缓冲作用。它确保数据在传输过程中不会丢失。
    

### DMA 如何工作？

DMA工作流程有以下几个步骤：

1. 准备阶段

首先，在开始任何数据传输之前，需要初始化和配置DMA控制器。这包括：

- 配置DMA通道：如果系统有多个DMA通道，需要选择或配置哪个通道负责当前的传输。
    
- 设置缓冲区：如果需要缓存数据，系统还需要设置DMA缓冲区来存储数据。
    
- 设定传输方向：指示数据传输是从外设到内存，还是从内存到外设。
    
- 指定地址和长度：确定数据从哪里开始传输，传输多大的数据量。
    

2. 外设发起请求

当一个外设（例如，硬盘、传感器或串口通信模块）需要进行数据读取或写入时，外设可以通过专门的控制线或者信号线（如DMA请求信号线）向DMA控制器发送请求。这个请求包括了需要传输的数据的起始地址、数据长度等信息。

具体来说，外设可能在以下情况下向DMA控制器发送请求：

- 数据准备就绪：外设已经准备好一段数据，并希望将其传输到内存中，或者从内存中读取数据并发送给外设。
    
- 缓冲区溢出或低水位标志：某些外设（如串行接口）可能在缓冲区数据达到一定量或者低于某个水位线时向DMA控制器发送请求，以便及时地将数据传输到内存或者从内存读取数据。
    
- 特定事件触发：外设可能在特定的硬件事件（如接收到数据包、完成一个数据块的处理等）发生时向DMA控制器发送请求，以便处理相关的数据传输任务。
    

3. DMA控制器工作阶段

DMA控制器在收到外设的数据传输请求后，会请求获取系统总线的控制权。一旦获得总线的控制权，DMA控制器就可以独立地管理和控制总线的访问，不再需要CPU的直接干预。

DMA控制器根据初始化时设置的参数，从外设的数据缓冲区读取数据，然后将数据传输到内存的指定位置；或者从内存读取数据，然后将数据传输到外设的数据缓冲区。这个过程中，DMA控制器可以直接访问总线，通过DMA通道进行数据的快速传输。

在数据传输完成或发生错误时，DMA控制器可以生成中断请求（如果配置了中断），通知CPU处理传输完成的事件或者错误情况。

4. CPU处理阶段

当DMA控制器完成数据传输后，或者在传输过程中发生错误时，它生成中断请求，CPU会响应中断，并执行相应的中断处理程序。在中断处理程序中，CPU可以读取DMA控制器的状态寄存器，确认数据传输的完成状态、传输的数据量等信息，并进行后续的数据处理或者通知其他相关任务。

5. CPU处理阶段

当DMA控制器完成数据传输任务后，它会释放系统总线的控制权，允许CPU或其他DMA通道继续使用总线进行数据访问。

### DMA的工作模式

DMA控制器支持两种传输模式：

1. Burst Mode（突发模式）

在突发模式下，DMA控制器会连续、一次性传输大量的数据，直到整个数据块传输完毕。在此期间，DMA控制器占用总线，不允许CPU访问内存。整个数据传输过程是连续的，不会中断。

当整个数据块传输完毕后，总线控制权将交还给 CPU  。这种传输的缺点是，如果 CPU 在此期间需要内存中的任何数据，则需要等到传输完成。

这是最快的 DMA 传输模式，因为一次可以传输大量数据。

这种模式的缺点是由于DMA控制器在整个数据传输过程中占用了系统总线，CPU无法访问内存，直到数据传输完成。如果CPU此时需要访问内存，必须等待DMA传输结束后才能进行。

2. Cycle Stealing Mode（周期窃取模式）

在周期窃取模式下，DMA控制器不会连续地占用总线。而是会周期性地占用总线，完成一小部分数据的传输后，控制权会暂时交还给CPU，让CPU也有机会访问内存进行处理。然后，DMA控制器再继续进行数据传输。

这样做的好处是CPU不会被完全占用。即使DMA控制器正在传输数据，CPU也能定期获得内存访问权，从而继续执行其他任务。这种模式让系统更加灵活，避免了CPU长时间等待。

缺点是由于DMA控制器每次只传输少量的数据，并且总线控制权频繁切换，因此传输效率较低，传输速度不如突发模式。

### DMA的传输类型

我们可以使用 DMA 进行以下类型的传输：

###### 1. 内存到外围设备

数据从 内存 中的指定位置传输到 外围设备（如硬盘、显示器、传感器等）。

假设你有一个数据处理程序，需要将一些存储在内存中的图像数据发送到一个显示器或打印机。通过DMA，内存中的数据可以直接传输到设备，而不需要CPU介入数据的搬运过程。

###### 2. 内存到内存

数据从一个 内存位置 传输到另一个 内存位置。这种传输方式通常用于大量数据的复制或搬移，例如将数据从一个缓冲区移动到另一个缓冲区，或者在不同的程序之间交换数据。

举个例子：你有一个大的数据数组，它存储在内存的一个位置。你想将这个数组复制到内存的另一个区域，以便进行不同的操作。通过DMA，数据可以在内存之间直接搬移，而无需CPU逐个字节地读取和写入。

###### 3. 外围设备到内存

数据从 外围设备（如硬盘、传感器、网络接口等）传输到 内存。这种模式通常用于外设采集的数据（例如传感器数据、网络数据包、文件从硬盘读取等）需要存储到内存中，以便后续的处理。

假设你有一个传感器，它会不断收集数据并传输到内存中。通过DMA，数据从传感器直接传输到内存，CPU无需参与每次数据的读取操作，只需等待数据传输完成后进行处理。
