- runBlocking
- 异常处理（Exception Handling）

- **抽象类和接口的区别？**
  - 抽象类是包含具体方法和抽象方法（无实现的方法）的类。抽象方法必须由抽象类的子类实现。抽象类不能被实例化，需要被继承后才能使用。
  - 接口类似于类的蓝图或契约（也可以看作是只包含方法但没有实现的类）。它包含空方法，这些方法代表其所有子类应共有的功能。子类需为每个方法提供实现。接口是被实现的。

- **你知道哪些访问修饰符？各自的作用是什么？**
  - Java 语言中有四种访问修饰符（从最严格到最宽松）：
    1. `private`（私有）：*变量*、*方法*、*构造函数*或*内部类*仅对其包含的类及其方法可见。例如，为了仅通过 getter 和 setter 方法访问变量，或隐藏不应被用户使用的类的底层实现以保持封装性，通常会使用此修饰符。单例模式的构造函数也会被标记为 `private`，以避免从外部进行不必要的实例化。
    2. `默认`（不使用关键字）：此修饰符可应用于*类*、*变量*、*构造函数*和*方法*，允许同一包内的类和方法访问。
    3. `protected`（受保护）：可用于*变量*、*方法*和*构造函数*，允许其所在类的子类以及同一包中的类访问。
    4. `public`（公共）：广泛用于*类*、*变量*、*构造函数*和*方法*，允许任何地方的任何类和方法访问。不应随处使用它，因为它意味着标记为 `public` 的数据不敏感，且不会被用于对程序造成损害。
- **接口能否实现另一个接口？**
  - 是的，一个接口可以实现另一个接口（甚至多个接口），但需要使用 `extends` 关键字，而非 `implements` 关键字。虽然不能从父接口中移除方法，但可以自由地向子接口添加新方法。

#### 对象与基本数据类型

- **String 类是如何实现的？为什么它被设计为不可变的？**

  - Java 语言中没有 String 类的基本数据类型变体——所有字符串都只是底层字符数组的包装器，该数组被声明为 `final`。这意味着一旦 String 对象被实例化，就无法通过语言的常规工具对其进行更改（反射仍然可能造成严重破坏，因为在 Java 中没有真正不可变的对象）。这就是为什么在类中，当你想要重写类的 `hashCode()` 和 `equals()` 方法时，String 变量是首选——你可以确保它们的所有必要约定都能得到满足。

    > 注意：String 类是不可变的，因此一旦创建，String 对象就不能被更改。String 类有许多方法，其中一些将在下面讨论，这些方法看起来像是修改字符串。由于字符串是不可变的，这些方法实际上所做的是创建并返回一个包含操作结果的新字符串。（[官方 Java 文档](https://link.gitcode.com/?target=https%3A%2F%2Fdocs.oracle.com%2Fjavase%2Ftutorial%2Fjava%2Fdata%2Fstrings.html&from=https%3A%2F%2Fgitcode.com%2Fgh_mirrors%2Fan%2Fandroid-interview-questions%3Fsource_module%3Dsearch_result_repo&lang=zh&theme=white)）

    这个类还有一个独特之处，当你像这样创建实例时：

    ```java
    String helloWorld = "Hello, World!";
    ```

    `"Hello, World!"` 被称为*字面量*，编译器会创建一个具有该值的 String 对象。因此

    ```java
    String capital = "Hello, World!".toUpperCase();
    ```

    是一个有效的语句，它首先会创建一个值为 "Hello, World!" 的对象，然后创建并返回另一个值为 "HELLO, WORLD!" 的对象。

  - String 被设计为不可变的，是为了防止在向服务器发送用户登录信息或其他敏感数据等情况下，数据被恶意篡改。

- **说 String 是不可变的意味着什么？**

  - 这意味着一旦创建，String 对象的 `char[]`（其包含的值）就被声明为 `final`，因此在运行时不能被更改。

- **Java 中的 `static` 关键字是什么意思？**
  - 对于 `static` 变量，意味着该变量（其值或它引用的对象）在封闭类的所有实例中共享（在一个实例中修改它会影响所有其他实例）；对于 `static` 方法，意味着这些方法可以在没有其封闭类实例的情况下被调用。例如，当创建不需要每次使用时都实例化的工具类时，这很有用。
- **Java 中的 `static` 方法可以被重写吗？**
  - 虽然子类可以用另一个具有相同签名的静态方法重写静态方法（返回类型可以向下转型），但这并不是真正的重写——它会被“隐藏”，但在适当的情况下仍然可以访问这两个方法（参见上面关于重载/重写的问题）。
- **`static` 块何时运行？**
  - static 块内的代码只执行一次：第一次创建该类的对象时，或者第一次访问该类的静态成员时（即使从未创建该类的对象）。
