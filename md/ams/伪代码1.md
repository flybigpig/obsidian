### 场景 1：Activity 启动（ATMS → AMS 请求创建进程）

```java
// ==================== ATMS 侧：ActivityStarter.java ====================

class ActivityStarter {
    ActivityTaskManagerService mService;
    ActivityTaskSupervisor mSupervisor;
    
    // 主入口：执行 Activity 启动
    int executeRequest(Request request) {
        // 1. 创建 ActivityRecord（包含 Activity 元信息）
        ActivityRecord r = new ActivityRecord.Builder(mService)
            .setIntent(request.intent)
            .setActivityInfo(request.activityInfo)
            .setCaller(request.callerApp)
            .build();
        
        // 2. 解析启动模式，确定 Task
        computeLaunchingTaskFlags();
        Task targetTask = computeTargetTask();
        if (targetTask == null) {
            targetTask = createNewTask(r);  // 创建新任务栈
        }
        r.setTask(targetTask);
        
        // 3. 检查目标进程是否存在
        WindowProcessController wpc = mService.getProcessController(
            r.processName, r.info.applicationInfo.uid);
        
        if (wpc != null && wpc.hasThread()) {
            // 进程已存在，直接启动 Activity
            mSupervisor.realStartActivityLocked(r, wpc, true, true);
        } else {
            // 【关键交互】进程不存在，请求 AMS 创建进程
            startProcessAsync(r, "activity");
        }
        return START_SUCCESS;
    }
    
    // 【关键方法】异步请求 AMS 创建进程（避免死锁）
    void startProcessAsync(ActivityRecord activity, String hostingType) {
        // 构建消息，通过 Handler 异步化（防止 ATMS 持锁时调用 AMS）
        final Message m = PooledLambda.obtainMessage(
            ActivityManagerInternal::startProcess,  // 目标方法
            mAmInternal,                            // AMS 的 LocalService
            activity.processName,
            activity.info.applicationInfo,
            false,  // knownToBeDead
            true,   // isTop（前台优先级）
            hostingType,
            activity.intent.getComponent()
        );
        
        // 发送到 ATMS 的 Handler 线程，释放锁后再执行
        mH.sendMessage(m);
    }
}

// ==================== AMS 侧：ActivityManagerService.LocalService ====================

class LocalService extends ActivityManagerInternal {
    ActivityManagerService mService;
    
    // ATMS 通过此接口请求创建进程
    @Override
    public void startProcess(String processName, ApplicationInfo info, 
                           boolean knownToBeDead, boolean isTop,
                           String hostingType, ComponentName hostingName) {
        synchronized (mService) {
            // 1. 查找或创建 ProcessRecord
            ProcessRecord app = mService.getProcessRecordLocked(processName, info.uid);
            if (app == null) {
                app = mService.newProcessRecordLocked(info, processName);
                mService.addProcessNameLocked(app);
            }
            
            // 2. 设置进程优先级标志
            int flags = 0;
            if (isTop) flags |= FLAG_TOP_APP;  // 前台应用标记
            
            // 3. 调用 ProcessList 真正创建进程（fork）
            mService.startProcessLocked(app, hostingType, hostingName);
        }
    }
}

// ==================== AMS 侧：ProcessList.java ====================

class ProcessList {
    
    ProcessRecord startProcessLocked(ProcessRecord app, String hostingType, 
                                     ComponentName hostingName) {
        // 1. 准备启动参数
        String entryPoint = "android.app.ActivityThread";
        
        // 2. 【关键】通过 Zygote 创建新进程
        ProcessStartResult result = Process.start(
            entryPoint,           // 类名：ActivityThread
            app.processName,      // 进程名
            app.uid, app.uid,     // uid/gid
            app.info.targetSdkVersion,
            app.info.dataDir,     // 数据目录
            ZYGOTE_POLICY_FLAG_EMPTY,  // Zygote 策略
            new String[]{PROC_START_SEQ_IDENT + app.startSeq}
        );
        
        // 3. 记录进程信息
        app.setPid(result.pid);
        app.startSeq = result.startSeq;
        
        // 4. 添加到进程列表
        mService.addProcessNameLocked(app);
        mLruProcesses.add(app);
        
        return app;
    }
}
```

### 场景 2：进程创建完成（AMS → ATMS 启动 Activity）

```java
// ==================== App 进程：ActivityThread.java ====================

public class ActivityThread {
    ApplicationThread mAppThread = new ApplicationThread();
    
    public static void main(String[] args) {
        // 1. 初始化主线程 Looper
        Looper.prepareMainLooper();
        
        // 2. 创建 ActivityThread 实例
        ActivityThread thread = new ActivityThread();
        
        // 3. 【关键】attach 到 AMS，通知进程已就绪
        thread.attach(false, startSeq);
        
        // 4. 开启消息循环
        Looper.loop();
    }
    
    private void attach(boolean system, long startSeq) {
        if (!system) {
            // 获取 AMS 的 Binder 代理
            final IActivityManager mgr = ActivityManager.getService();
            
            try {
                // 【关键交互】跨进程调用 AMS.attachApplication()
                mgr.attachApplication(mAppThread, startSeq);
            } catch (RemoteException e) {
                throw e.rethrowFromSystemServer();
            }
        }
    }
}

// ==================== AMS 侧：ActivityManagerService.java ====================

public class ActivityManagerService extends IActivityManager.Stub {
    
    // 接收 App 进程的 attach 请求
    @Override
    public final void attachApplication(IApplicationThread thread, long startSeq) {
        synchronized (this) {
            attachApplicationLocked(thread, startSeq);
        }
    }
    
    private boolean attachApplicationLocked(IApplicationThread thread, long startSeq) {
        // 1. 根据 startSeq 找到对应的 ProcessRecord
        ProcessRecord app = mProcessList.getProcessRecordByStartSeq(startSeq);
        app.makeActive(thread);  // 绑定远程接口
        
        // 2. 更新进程信息
        app.setPid(Binder.getCallingPid());
        app.thread = thread;  // 保存 IApplicationThread 代理
        
        // 3. 【关键】创建 WindowProcessController，与 ATMS 共享
        app.mWindowProcessController = new WindowProcessController(app);
        
        // 4. 绑定 Application（创建 Application 对象）
        thread.bindApplication(processName, appInfo, providers, ...);
        
        // 5. 【关键交互】委托 ATMS 启动 Activity
        boolean didSomething = false;
        if (normalMode) {
            try {
                // 通过 LocalService 接口调用 ATMS
                didSomething = mAtmInternal.attachApplication(
                    app.getWindowProcessController());
            } catch (Exception e) {
                Slog.wtf(TAG, "Exception launching activities", e);
            }
        }
        
        // 6. 启动pending的 Service 和 Broadcast
        didSomething |= mServices.attachApplicationLocked(app, processName);
        didSomething |= sendPendingBroadcastsLocked(app);
        
        return didSomething;
    }
}

class LocalService extends ActivityTaskManagerInternal {

    @Override
    public boolean attachApplication(WindowProcessController wpc) {
        synchronized (mService.mGlobalLockWithoutBoost) {

        }
    }

// ==================== ATMS 侧：RootWindowContainer.java ====================

class RootWindowContainer {
    
    boolean attachApplication(WindowProcessController app) {
        // 遍历所有 Display，查找该进程待启动的 Activity
        for (int displayNdx = getChildCount() - 1; displayNdx >= 0; --displayNdx) {
            DisplayContent display = getChildAt(displayNdx);
            
            // 查找栈顶的 ActivityRecord
            ActivityRecord top = display.getTopActivity();
            if (top != null && !top.attachedToProcess()) {
                if (top.processName.equals(app.mName) && top.info.applicationInfo.uid == app.mUid) {
                    // 【关键】真正启动 Activity
                    return mTaskSupervisor.realStartActivityLocked(top, app, true, true);
                }
            }
        }
        return false;
    }
}

// ==================== ATMS 侧：ActivityTaskSupervisor.java ====================

class ActivityTaskSupervisor {
    
    boolean realStartActivityLocked(ActivityRecord r, WindowProcessController proc,
                                    boolean andResume, boolean checkConfig) {
        // 1. 创建 ClientTransaction（事务机制）
        final ClientTransaction transaction = ClientTransaction.obtain(
            proc.getThread(),  // IApplicationThread
            r.token            // Activity 的 Binder token
        );
        
        // 2. 添加 LaunchActivityItem（创建 Activity）
        transaction.addCallback(LaunchActivityItem.obtain(
            new Intent(r.intent),
            r.info,
            r.getSavedState(),  // 恢复状态
            ...
        ));
        
        // 3. 设置最终生命周期状态
        if (andResume) {
            transaction.setLifecycleStateRequest(
                ResumeActivityItem.obtain(proc.getReportedProcState(), true));
        } else {
            transaction.setLifecycleStateRequest(PauseActivityItem.obtain());
        }
        
        // 4. 【关键】通过 ClientLifecycleManager 调度事务
        mService.getLifecycleManager().scheduleTransaction(transaction);
        
        r.attachedToProcess = true;
        return true;
    }
}
```

```java
class ClientLifecycleManager {
    
    void scheduleTransaction(ClientTransaction transaction) throws RemoteException {
        // 获取 App 进程的远程接口
        final IApplicationThread client = transaction.getClient();
        
        // 【关键】跨进程调用 App 进程的 scheduleTransaction
        transaction.schedule();
        
        // 记录日志、性能统计等
        if (DEBUG) Slog.v(TAG, "Scheduled transaction: " + transaction);
    }
}

        // 跨进程回调 App 进程

// ==================== App 进程：TransactionExecutor.java ====================

class TransactionExecutor {
    
    void execute(ClientTransaction transaction) {
        // 1. 执行所有前置回调（LaunchActivityItem、NewIntentItem等）
        executeCallbacks(transaction);
        
        // 2. 执行最终生命周期状态（ResumeActivityItem等）
        executeLifecycleState(transaction);
    }
    
    void executeCallbacks(ClientTransaction transaction) {
        final List<ClientTransactionItem> callbacks = transaction.getCallbacks();
        for (ClientTransactionItem item : callbacks) {
            item.execute(mTransactionHandler, transaction.getToken(), mPendingActions);
        }
    }
}

// ==================== App 进程：LaunchActivityItem.java ====================

class LaunchActivityItem extends ClientTransactionItem {

    public void execute(ClientTransactionHandler client, IBinder token,

        // 创建 ActivityClientRecord

        // 【关键】调用 ActivityThread 处理启动

}

        r.createdConfig = new Configuration(mConfiguration);
        
        // 4. 报告 Activity 创建完成（反向通知 ATMS）
        // ...
    }
    return a;
}

private Activity performLaunchActivity(ActivityClientRecord r, Intent customIntent) {
    // 1. 创建 Activity 实例（反射）
    Activity activity = mInstrumentation.newActivity(
        r.token, r.packageInfo, r.intent, ...);

    // 3. 关联 Context、Window 等
    activity.attach(appContext, this, r.token, r.ident, ...);
    
    // 4. 调用 onCreate
    mInstrumentation.callActivityOnCreate(activity, r.state);
    
    return activity;
}
```

```java
    }
}

// ==================== AMS 侧：ActivityManagerInternal 实现 ====================

class LocalService extends ActivityManagerInternal {
    
    @Override
    public void updateActivityUsageStats(ActivityRecord activity, int event) {
        synchronized (mService) {
            // 1. 更新 Activity 使用统计
            mService.mUsageStatsService.reportEvent(activity, event);
            
            // 2. 【关键】更新进程优先级（oom_adj）
            ProcessRecord app = activity.app;
            if (app != null) {
                mService.updateOomAdjLocked(app, event);
            }
        }
    }
    
    // 更新进程优先级
    void updateOomAdjLocked(ProcessRecord app, int event) {
        // 根据 Activity 状态调整 oom_adj
        switch (event) {
            case ACTIVITY_RESUMED:
                app.oomAdj = FOREGROUND_APP_ADJ;  // 0
                break;
            case ACTIVITY_PAUSED:
                app.oomAdj = VISIBLE_APP_ADJ;     // 1
                break;
            case ACTIVITY_STOPPED:
                app.oomAdj = CACHED_APP_ADJ;      // 9
                break;
        }
        
        // 应用新的 oom_adj 到内核
        applyOomAdjLocked(app);
    }
}
```

## 四、关键设计模式总结

| 设计模式 | 应用场景 | 代码体现 |
|---------|---------|---------|
| **双向引用** | AMS ↔ ATMS 互相调用 | `mAm` 和 `mAtm` 字段 |
| **LocalService** | 同进程内直接方法调用 | `LocalService extends XXXInternal` |
| **Handler 异步化** | 避免持锁时跨服务调用 | `startProcessAsync()` 使用 `mH.sendMessage()` |
| **事务机制** | 批量执行生命周期操作 | `ClientTransaction` + `TransactionExecutor` |
| **代理模式** | 跨进程通信 | `IApplicationThread.Stub` / `IActivityManager.Stub` |
| **观察者模式** | 状态变更通知 | `updateActivityUsageStats()` 回调 |

## 五、完整调用链总结

```
【Activity 冷启动完整流程】

1. App 调用 startActivity()
   ↓ Binder IPC
2. ATMS.startActivity() → ActivityStarter.execute()
   ↓ 同进程调用
3. 发现进程不存在 → ATMS.startProcessAsync()
   ↓ Handler 消息（异步化）
4. AMS.LocalService.startProcess()
   ↓ 同进程调用
5. ProcessList.startProcess() → Zygote.fork()
   ↓ 进程创建完成
6. ActivityThread.main() → AMS.attachApplication()
   ↓ Binder IPC
7. AMS.attachApplicationLocked()
   ↓ 同进程调用（LocalService）
8. ATMS.LocalService.attachApplication()
   ↓ 同进程调用
9. RootWindowContainer.attachApplication() → realStartActivityLocked()
   ↓ 构建事务
10. ClientLifecycleManager.scheduleTransaction()
    ↓ Binder IPC
11. ApplicationThread.scheduleTransaction()
    ↓ Handler
12. TransactionExecutor.execute()
    ↓ 反射 + 回调
13. Activity.onCreate() → onResume()
```

通过以上伪代码，可以清晰看到 **AMS 负责"进程工厂"（创建/管理进程），ATMS 负责"Activity 舞台"（调度/管理界面）**，两者通过 **LocalService 接口** 和 **事务机制** 实现高效协作。
